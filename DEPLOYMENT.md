# Deployment

This repository is prepared for the GitHub Pages project URL:

`https://sanazrabinia1.github.io/website/`

In GitHub:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save.

The site uses the `yaoyao-liu/minimal-light` remote Jekyll theme.
